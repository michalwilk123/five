### Description

This is the indexer for programming projects. It is comparable to applications like jedi / pylance / pyright / eslint

Copared to all of the above, it is a more general purpose indexer that can be used for any 
programming language. It is possible because the parsing is done by large language model!

Because of that the indexing is quite an expensive operation and I do a lot of diff-checking to avoid 
re-indexing the same file over and over again.
